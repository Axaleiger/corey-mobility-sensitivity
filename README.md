# Corey Mobility Sensitivity

Интерактивная визуализация оценки чувствительности параметров Corey (`ao`, `aw`, `krw`) к полной подвижности.

## Что внутри

- Профиль подвижности `M(kin)` — база vs текущий сценарий
- Кратность `M / Mbase` с пределом **3×**
- Границы one-at-a-time (OAT) для ячеек C3 / D3 / E3
- Tornado-диаграмма на краях диапазонов

## Запуск локально

Откройте `index.html` в браузере — зависимости подтягиваются с CDN (Chart.js, Google Fonts).

## Параметры базы (Excel)

| Ячейка | Параметр | База | Допуск ≤3× |
|--------|----------|------|------------|
| C3 | ao | 3.05 | 1.69 → 4.76 |
| D3 | aw | 5 | 3.32 → 6.68 |
| E3 | krw | 0.1 | 0.033 → 0.30 |

Критерий: `max_i max(M_i/Mbase_i, Mbase_i/M_i) ≤ 3`.
