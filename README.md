# Corey Mobility Sensitivity

Интерактивная визуализация оценки чувствительности параметров Corey (`ao`, `aw`, `krw`) к полной подвижности.

## Что внутри

Вкладки:

1. **Чувствительность** — профиль `M(kin)`, кратность vs база (предел 3×), OAT-границы, tornado
2. **Гиперкуб** — 3D объём αo × αw × krw, цвет = подвижность; срезы в плоскостях с фикс. αo / αw / krw (2D heatmap + легенда)
3. **Входные данные** — правка μw, μo, max_kin, Δkin, N, базы Corey и ряда КИН

## Запуск локально

Откройте `index.html` в браузере — зависимости с CDN (Chart.js, Plotly, Google Fonts).

| Ячейка | Параметр | База | Допуск ≤3× |
|--------|----------|------|------------|
| C3 | ao | 3.05 | 1.69 → 4.76 |
| D3 | aw | 5 | 3.32 → 6.68 |
| E3 | krw | 0.1 | 0.033 → 0.30 |

Критерий: `max_i max(M_i/Mbase_i, Mbase_i/M_i) ≤ 3`.
